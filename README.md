# Доктор Хвост

Учебный сайт ветклиники: владелец записывается сам, администратор видит очередь дня, врач пишет протокол в карту. Рядом лежат материалы лабораторных 1–11 курса «Управление ИТ-проектами».

Сайт написан на Node.js без сторонних пакетов: на этом компьютере стоит Node.js, Python не установлен. Расчёты лабораторных 3, 6, 9 и 10 тоже запускаются через `node`.

## Открыть в VS Code

1. Файл → Открыть папку → эта папка.
2. Терминал → Выполнить задачу → **Запустить сайт ветклиники**.
3. В браузере открыть http://127.0.0.1:8000

Та же команда из терминала:

```powershell
node src/server.js
```

Проверка:

```powershell
node --test
```

## Учебные входы

| Почта | Пароль | Что видит |
| --- | --- | --- |
| admin@khvost.local | Admin12345 | сводка и журнал |
| reception@khvost.local | Reception12345 | очередь и пациенты |
| vet@khvost.local | Vet12345 | очередь и протокол |
| client@khvost.local | Client12345 | только свои животные |

Пароли демонстрационные. Перед настоящей клиникой их меняют и убирают блок на странице входа.

## Где какая лабораторная

Оглавление: [docs/INDEX.md](docs/INDEX.md).

Живой заказчик и неделя замера времени в клинике в эту сборку не входят. Такие места помечены словом «допущение» или прямой оговоркой. Подставлять выдуманную встречу нельзя: оценка за это как раз и снимается.
