# Доктор Хвост

Учебный сайт ветеринарной клиники. Владелец сам регистрируется, добавляет питомцев и записывается на свободное время к врачу. Регистратура видит очередь дня и отмечает приход, врач пишет протокол приёма в карту, администратор видит сводку, правит цены и смотрит журнал действий.

Сайт написан на Node.js без сторонних пакетов. Данные хранятся в базе **SQLite** через встроенный модуль `node:sqlite`, поэтому `npm install` не нужен.

## Требования

Node.js **22.13 или новее** (проверить: `node -v`). На версиях 22.5–22.12 запускайте с флагом: `node --experimental-sqlite src/server.js`.

## Запуск

```powershell
npm start
```

Откройте http://127.0.0.1:8000

В VS Code: Терминал → Выполнить задачу → **Запустить сайт ветклиники**.

При первом запуске создаётся файл `data/clinic.db` с демонстрационными данными. Начать с чистой базы: `npm run reset-db`.

Тесты: `npm test`.

## Учебные входы

| Почта | Пароль | Что видит |
| --- | --- | --- |
| admin@khvost.local | Admin12345 | сводка, цены, журнал, очередь |
| reception@khvost.local | Reception12345 | очередь, отметка прихода и отмена |
| vet@khvost.local | Vet12345 | свои пациенты и протокол |
| client@khvost.local | Client12345 | только свои животные и записи |

Ещё два врача: surgeon@khvost.local и derm@khvost.local, пароль Vet12345. Пароли демонстрационные: перед настоящей работой их меняют и убирают блок с ними со страницы входа.

## Устройство базы

| Таблица | Что хранит |
| --- | --- |
| `users` | все пользователи и их роль: admin, reception, vet, client |
| `sessions` | активные входы (cookie `sid`) и CSRF-токены |
| `doctors` | специализация и описание врачей |
| `services` | услуги, цены и длительность |
| `pets` | питомцы владельцев |
| `appointments` | записи на приём и их статус |
| `records` | протоколы приёмов: диагноз, лечение, рекомендации, вес |
| `audit_log` | журнал действий |

Уникальный индекс `appt_vet_slot` не даёт записать двух пациентов к одному врачу на одно время (отменённые записи не мешают).

## Безопасность

- пароли хранятся как хеш scrypt с солью;
- сессии в базе, cookie `HttpOnly` и `SameSite=Lax`;
- каждая форма проверяет CSRF-токен;
- все данные в HTML экранируются, запросы к базе только с параметрами;
- права проверяются на сервере: владелец видит только своих животных, протокол пишет только врач этого приёма.
