# Доктор Хвост

Учебный сайт сети ветеринарных клиник в Астане на Node.js с базой данных **SQLite**. Сторонних пакетов нет: `npm install` не нужен.

**10 филиалов на карте** (Leaflet + OpenStreetMap), 20 врачей, 12 услуг, ~60 питомцев и около 2 900 приёмов за два месяца в демо-данных. Все иллюстрации (животные, портреты врачей, иконки) нарисованы для сайта в SVG — `src/art.js`. Настоящие фото врачей загружает администратор, фото питомцев — владельцы.

## Что умеет

**Для всех**
- главная: услуги с иконками, карта филиалов, врачи с лучшими отзывами, отзывы владельцев;
- `/branches` — карта и карточки 10 филиалов: адрес, часы, телефон, хирургия/лаборатория/стационар, врачи филиала;
- `/doctors` — все врачи с фильтром по специализации и филиалу.

**Владелец**
- регистрация и вход, кабинет с питомцами;
- фото питомца (JPG, PNG, WebP до 2 МБ, хранится в базе);
- онлайн-запись: выбор филиала → врача → свободного времени (по графику врача и длительности услуги);
- перенос и отмена записи;
- напоминание о прививке, если последней вакцинации больше года (или её не было);
- история приёмов с диагнозами и отзыв о приёме (1–5 звёзд), средняя оценка врача видна на главной.

**Регистратура**
- очередь дня: «Пришёл», «Отмена»;
- запись по телефону: найти владельца по номеру или завести новую карту. Если такой владелец потом зарегистрируется на сайте с тем же телефоном, он увидит свою карту;
- счёт: услуга + препараты и материалы, оплата наличными или картой, чек для печати.

**Врач**
- свои пациенты на день, протокол приёма (диагноз, лечение, рекомендации, вес);
- поиск пациентов по кличке, владельцу или части телефона, полная медкарта.

**Администратор**
- сводка и журнал всех действий;
- отчёты за любой период: выручка по дням, загрузка врачей, популярные услуги, графики и таблицы;
- выгрузка записей в Excel (CSV);
- сотрудники: добавить, сменить пароль, заблокировать; филиал, фото, график приёма врача по дням недели, отпуска;
- отчёт по филиалам: выручка, приёмы, средний чек;
- прайс услуг и препаратов;
- резервная копия базы одной кнопкой, скачивание копий.

**Безопасность:** пароли — хеш scrypt; после 5 неверных паролей вход по этой почте закрыт на 5 минут; CSRF-токен в каждой форме; экранирование HTML; запросы к базе только с параметрами; права проверяются на сервере.

## Запуск

Нужен Node.js **22.13 или новее** (`node -v`).

```powershell
node src/server.js
```

или `npm start` (в PowerShell, если `npm` ругается на выполнение сценариев, — `npm.cmd start`).

Откройте http://127.0.0.1:8000

При первом запуске создаётся `data/clinic.db` с демо-данными за последние 60 дней. Если база осталась от прошлой версии сайта, она **обновится сама** (миграции), данные сохранятся. Чтобы увидеть новые демо-данные (филиалы, врачей, историю), остановите сайт и выполните `npm run reset-db` — база создастся заново.

Карте нужен интернет (тайлы OpenStreetMap). Без интернета на месте карты появится подсказка, а список адресов останется.

Тесты: `npm test` (25 проверок).

## База данных

| Таблица | Что хранит |
| --- | --- |
| `branches` | 10 филиалов: адрес, координаты, часы, телефон, хирургия/лаборатория/стационар |
| `users` | пользователи, роль, блокировка, признак «записан по телефону» |
| `sessions` | активные входы и CSRF-токены |
| `doctors` | специализация, филиал, пол, стаж, описание врача |
| `staff_photos` | фото врачей (BLOB) |
| `vet_schedule` | график врача по дням недели |
| `vet_time_off` | отпуска и выходные врачей |
| `services` | услуги, цена, длительность, категория, иконка, признак вакцинации |
| `items` | препараты и материалы для счёта |
| `pets` | питомцы |
| `pet_photos` | фото питомцев (BLOB) |
| `appointments` | записи: филиал, время, длительность, цена на момент записи, статус, оплата |
| `invoice_lines` | строки счёта |
| `records` | протоколы приёмов |
| `reviews` | отзывы и оценки |
| `audit_log` | журнал действий |

Версия схемы хранится в `PRAGMA user_version`, изменения — в массиве `MIGRATIONS` в `src/db.js`. Пересечение записей одного врача по времени проверяется с учётом длительности услуги (`src/schedule.js`), а уникальный индекс `appt_vet_slot` дополнительно защищает от двух записей на одно начало.

Посмотреть базу можно программой [DB Browser for SQLite](https://sqlitebrowser.org).

## Резервные копии

Управление → Резервные копии → «Создать копию сейчас». Копии лежат в папке `backups/` (хранятся последние 30). Как восстановить — написано на той же странице.

## Ссылка для всех (публикация в интернете)

Проще всего — **Render.com**, бесплатно:

1. Зарегистрируйтесь на https://render.com через GitHub.
2. **New → Blueprint** → выберите репозиторий `my-site` → **Apply**. Настройки берутся из `render.yaml`, сайт собирается по `Dockerfile`.
3. Через несколько минут появится ссылка вида `https://doktor-khvost.onrender.com`.

Ограничения бесплатного тарифа: после 15 минут без посетителей сайт «засыпает», первое открытие занимает до минуты; **постоянного диска нет — при каждом перезапуске база создаётся заново с демо-данными.** Для учебного показа это подходит. Чтобы данные сохранялись, на платном тарифе добавьте диск (Disk, путь `/data`) — база уже пишется в `/data/clinic.db`.
