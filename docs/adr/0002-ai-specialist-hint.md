# ADR 0002. Подсказка специалиста по жалобе владельца (ЛЗ 12)

- **Статус:** принято условно — функция включается в рабочем режиме только после прогона модели на наборе `evals/dataset.jsonl` и выполнения критерия приёмки. До этого на сайте работает базовое решение без ИИ (правила).
- **Дата:** 24.11.2026
- **Кто принимает:** команда проекта «Доктор Хвост», согласует заказчик (администратор клиники).

## Контекст

Владелец при онлайн-записи и регистратура при записи по телефону выбирают врача сами. Ошибка в выборе (например, к терапевту вместо дерматолога) означает перенос записи и лишний визит. Поле «Что беспокоит» уже есть в форме записи — по нему можно подсказать специальность.

Тексты жалоб могут содержать персональные данные владельца (имя, телефон, адрес — люди пишут их в свободное поле) и сведения о здоровье животного. Они относятся к данным клиники и не должны покидать её сервер без необходимости (Закон РК «О персональных данных и их защите», требование хранить ПДн граждан РК на территории РК).

## Решение

1. Подсказка — **необязательная**: она не выбирает врача за человека, а предлагает специальность и кнопку «Показать врачей». Пометка «ИИ» и пояснение видны рядом с подсказкой.
2. Модель — **локальная** (`qwen2.5:3b` через Ollama на сервере клиники). Площадка выбрана **не по цене**: внешний API дешевле (см. расчёт в отчёте), но тогда тексты жалоб уходят зарубежному провайдеру.
3. Правило отказа: модель может ответить «не уверен», тогда подсказка не показывается. Правила без ИИ не показывают подсказку, если не сработал ни один признак.
4. Если модель недоступна — сайт автоматически использует правила; запись работает всегда.
5. Текст жалобы в журнал подсказок не записывается — только длина, ответ, источник и время.

## Критерий приёмки (когда включаем модель)

- macro F1 модели на наборе выше, чем у правил, **не менее чем на 0,05**;
- модель **не хуже правил ни по одному классу** (F1 по каждому классу);
- полнота класса «неотложно» **не ниже 0,90** (пропуск неотложного случая — худший сценарий);
- среднее время ответа на сервере клиники — не больше 3 секунд.

Если хотя бы один пункт не выполнен — остаёмся на правилах без ИИ.

## Отвергнутые варианты

| Вариант | Почему отвергнут |
|---|---|
| Внешний API (Claude Haiku 5.5, $0,10 / $0,50 за 1 млн токенов) | Дешевле своего сервера на нашем объёме, но тексты с ПДн уходят провайдеру за рубежом; нужно отдельное согласие владельцев и договор. Решение не про цену. |
| Модель выбирает врача сама и сразу записывает | Цена ошибки — визит не к тому врачу или пропущенный неотложный случай; человек должен оставаться в контуре. |
| Только правила, без ИИ | Остаётся запасным вариантом и точкой отсчёта. Хуже на коротких, смешанных (каз./рус.) и двусмысленных жалобах — проверяется замером. |
| Модель 7b | Нужно 16 ГБ ОЗУ; сервер клиники рассчитан на 8 ГБ (допущение). |

## Критерий пересмотра

- доля принятых подсказок (страница «ИИ-подсказки») ниже 50 % за месяц при 100+ подсказках;
- хоть один пропущенный неотложный случай, найденный при разборе;
- набор оценки пополнен реальными обезличенными жалобами (≥ 100) — повторить замер;
- клиника получает согласие владельцев на обработку внешним провайдером — пересмотреть выбор площадки.
